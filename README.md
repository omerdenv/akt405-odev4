# AKT405 Ödev 4 - Finansal Veri Analizi

## Proje Açıklaması

Bu projede finansal varlıkların geçmiş fiyat verileri kullanılarak getiri ve risk analizleri yapılmıştır.

Analizde aşağıdaki varlıklar kullanılmıştır:

- THYAO (Türk Hava Yolları)
- ASELS (Aselsan)
- BIST100 Endeksi

Veriler Yahoo Finance üzerinden alınmıştır.

## Kullanılan Teknolojiler

- Python 3.11
- Pandas
- NumPy
- Matplotlib
- yFinance

## Veri Aralığı

Analizde kullanılan tarih aralığı:

01.01.2021 - 31.12.2025

## Yapılan Analizler

Projede aşağıdaki işlemler gerçekleştirilmiştir:

- Günlük kapanış fiyatlarının çekilmesi
- Basit getiri hesaplama
- Log getiri hesaplama
- Yıllık ortalama getiri hesaplama
- Yıllık volatilite (risk) hesaplama
- Varlık performans karşılaştırması
- Getiri korelasyon analizi

## Çıktılar

Oluşturulan dosyalar:

- data/kapanis.csv
- data/getiri_risk.csv
- plots/portfoy.png
- plots/korelasyon.png

## Sonuç

Analiz sonucunda farklı finansal varlıkların getiri ve risk seviyeleri karşılaştırılmıştır. Korelasyon analizi kullanılarak varlıklar arasındaki ilişki incelenmiştir.
